Welcome to the TanzaniteMod for Minecraft! This mod adds a variety of new items, tools, and blocks to enhance your Minecraft experience.

## Features

- **Tanzanite Sword**: A powerful new weapon.
- **Tanzanite Pickaxe**: A durable and efficient mining tool.
- **Tanzanite Axe**: A robust tool for chopping wood.
- **Tanzanite Shovel**: A reliable tool for digging.
- **Custom Item**: A unique item with special properties.
- **Custom Material Armor**: Full set of armor including helmet, chestplate, leggings, and boots.
- **Custom Block**: A new building block for your creations.
- **Custom Ore Generation**: New ores added to the overworld.

## Installation

1. **Download and install Minecraft Fabric**: Ensure you have the Fabric mod loader installed. You can download it [here](https://fabricmc.net/).

2. **Install the TanzaniteMod**:
   - Download the latest version of the mod from the [releases page](link to your mod release).
   - Place the downloaded mod file in your Minecraft `mods` folder. This folder is usually located in `.minecraft/mods`.

3. **Run Minecraft**: Launch Minecraft with the Fabric profile.

## Usage

- The mod will automatically add the new items, tools, and blocks to the game.
- You can find the new ore in the overworld.
- Craft the new items and tools as you would with any other in-game items.
